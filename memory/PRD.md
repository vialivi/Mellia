# Camell Flowrist Microsite PRD

## Original problem statement
Build a stylish, playful, girly, aesthetic microsite/landing page for Camell Flowrist, a Bouquet, Hampers and Flowers business, using the supplied WhatsApp, Instagram and TikTok links. The visual direction selected was Garden Boutique: sage green, cream, natural flowers and whimsical details. Social imagery is inspiration only.

## Architecture decisions
- React single-page landing experience with direct external WhatsApp/social CTAs.
- Framer Motion for staged hero reveal, scroll reveals, layout transitions and FAQ animation.
- Lenis for smooth momentum scrolling.
- External Unsplash/Pexels photography used as curated visual references; no backend data or auth required for this marketing flow.
- Responsive CSS with a dedicated mobile navigation panel and reduced-motion fallback.

## Implemented
- Original Camell Flowrist wordmark treatment, floral mark and matching SVG favicon.
- Kinetic sage/cream hero with masked line-by-line reveal, parallax image moment and editorial marquee.
- Filterable Bouquet, Hampers and Flowers catalog with direct product-to-WhatsApp links.
- Custom order builder with occasion, date and budget fields that composes a WhatsApp message.
- Testimonials, story section, FAQ accordion, floating WhatsApp action and Instagram/TikTok links.
- Responsive desktop/mobile composition and mobile menu navigation.
